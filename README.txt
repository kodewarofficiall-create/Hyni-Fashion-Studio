Add your future desktop video:
1. Generate/export a landscape video in MP4 format, ideally 1920x1080 (16:9).
2. Name it exactly: grand-opening-desktop.mp4
3. Put it inside the assets folder, beside grand-opening-mobile.mp4.
4. Upload index.html and the entire assets folder to your hosting.

Video behavior:
- Desktop (761px and wider): assets/grand-opening-desktop.mp4
- Mobile (760px and narrower): assets/grand-opening-mobile.mp4 (your original uploaded video)

Important: both MP4 files must use the H.264 (AVC) codec. HEVC/H.265 files
will show a blank screen on many Android phones and desktop browsers. The
original HEVC mobile file was converted to H.264 and kept as
grand-opening-mobile-hevc-original.mp4 for reference.
